# Sigma Precisions

Premium static marketing site for [sigmaprecisions.com](https://sigmaprecisions.com) — precision design, prototype, test, and manufacture for power, aerospace, and oil & gas.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Stack

- Astro (static)
- Tailwind CSS v4
- Formspree / Netlify Forms for contact

See [DEPLOY.md](./DEPLOY.md) for Cloudflare Pages / Netlify and DNS for `sigmaprecisions.com`.

## Brand

See [BRAND.md](./BRAND.md) and the live brand book at `/brand`. Logo SVGs are in `public/brand/`.

## Site content

Company details live in `src/site.ts` (address, email, phone). Brand tokens & voice live in `src/brand.ts`.
